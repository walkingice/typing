# Typing

簡單的打字練習網站，提供兩款遊戲：字母練習與單字打字遊戲。開啟首頁後，可以使用左側 tabs 切換遊戲。網站使用 vanilla JavaScript、HTML 與 CSS 製作，也可以儲存到本機，在沒有網路的環境下使用。

## 遊戲

### 字母

「字母」遊戲適合練習英文小寫字母與常用符號。

- 提供「字母」、「字母符號」與「字母反覆」三種練習目標。
- 按下第一個按鍵後才開始計時，完成後顯示花費時間。
- 正確輸入的字元會變成綠色，錯誤輸入會變成紅色；可以使用 Backspace 修正。
- 可切換畫面下方的虛擬鍵盤，並查看目前應輸入的按鍵。
- 每個練習目標會個別記錄 High Score，資料儲存在瀏覽器的 localStorage。

### 單字

「單字」遊戲是類似 Tetris 的落下方塊遊戲。單字會隨著方塊從上方落下，輸入畫面上的單字即可消除對應方塊並取得分數。

- 開始遊戲前輸入玩家姓名、選擇單字列表與難度。
- 難度分為 Easy、Normal 與 Hard，難度越高，方塊落下速度與得分倍率越高。
- 方塊堆到畫面頂端時遊戲結束。
- 可在排行榜查看前 10 名成績。
- 內建英文單字、中文常見字與 `a`–`z` 預設列表。
- 可上傳、刪除及管理自訂單字列表。

## 自訂單字列表格式

請將檔案儲存為 `.txt`，第一行是列表名稱，第二行開始每行放一個單字或字元：

```text
-檔案名稱-第一行
-第二
-行
-開始
-都是
-可能
-被
-輸出
-的
-內容
```

在「單字」遊戲的設定畫面選擇「上傳新列表」即可匯入。

## 使用方式

直接開啟根目錄的 `index.html`，或使用靜態網站伺服器提供此目錄，即可從首頁開始遊玩。
